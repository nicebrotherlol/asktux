# asktux

## Description:
A small 8Ball question answer CLI-Tool inspired by tux

## Why?
This is a fun project, since I often have trouble deciding

## Requirements:
Python3

## How it works:
Once installed just type "asktux" followed by your question.
e.g. asktux "Will I become famous?"

## Install:
```
git clone https://github.com/nicebrotherlol/asktux.git
cd asktux
chmod +x install.sh
./install.sh
```
